# Support

Community support is provided through GitHub issues and discussions for the public repository.

Before requesting help:

1. Read `docs/FAQ.md` and `docs/TROUBLESHOOTING.md`.
2. Run `python scripts/forensic_audit.py --root .`.
3. Run the installer with `--plan` when diagnosing input or DNS assumptions.
4. Remove every secret, personal identifier, mailbox message and infrastructure credential from diagnostics.

Operational emergencies on production mail servers require a qualified Linux/mail administrator. The project does not provide a hosted service, uptime warranty or guaranteed recovery service.

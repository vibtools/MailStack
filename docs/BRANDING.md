# MailStack branding and attribution

## Canonical identity

| Item | Approved value |
|---|---|
| Product name | **MailStack** |
| Publisher | **Vib Tools** |
| Repository | `vibtools/MailStack` |
| Repository URL | https://github.com/vibtools/MailStack |
| Product attribution | **MailStack by Vib Tools** |
| Open-source hub | https://dev.vib.tools/ |
| Company website | https://vib.tools/ |

Use **MailStack** as one word with capital `M` and capital `S`.

Use **Vib Tools** as the company and publisher name in prose. The domain-style `Vib.Tools` form may be used only where it is part of an approved visual lockup or domain reference.

## Positioning

Preferred product description:

> Open-source self-hosted mail server and shared team inbox built with Postfix, Dovecot LMTP, Django, MariaDB, Maildir, Nginx, and Ubuntu.

Preferred short tagline:

> Self-hosted mail server and shared team inbox.

Do not describe the reference deployment as a complete Gmail or Microsoft 365 replacement. It is intentionally receive-only and does not expose IMAP, POP3, remote SMTP submission, outbound campaigns, or public account registration.

## Visual system

The MailStack product identity follows the Vib Tools blue, cyan, and dark visual system.

| Token | Value | Use |
|---|---|---|
| Brand dark | `#000713` | Primary dark background |
| Primary blue | `#0647ED` | Core brand accent |
| Bright blue | `#087AFF` | Gradient and interactive accent |
| Cyan | `#08E0DE` | Highlight and gradient accent |
| White | `#FFFFFF` | Light background and high-contrast text |

The canonical repository icon is `assets/mailstack-logo.svg`.

## Logo use

- Preserve the original aspect ratio.
- Maintain clear space around the icon.
- Do not recolor individual elements outside the approved palette.
- Do not add shadows, outlines, rotations, or unapproved effects.
- Do not place the icon on a background that removes contrast.
- Do not present modified forks as official MailStack releases.

## Repository and documentation rules

All public source, citation, security, release, badge, and support links must point to:

```text
https://github.com/vibtools/MailStack
```

Internal runtime identifiers are not part of the public branding system. They remain temporarily unchanged for backward compatibility; see `REBRAND_COMPATIBILITY.md`.

## Trademark and fork attribution

The AGPL applies to source code. It does not automatically grant trademark rights in the MailStack or Vib Tools names, logos, visual identity, or trade dress.

Forks may state that they are derived from MailStack and must preserve required legal notices. Modified distributions should use clearly distinguishable branding unless written permission authorizes official branding use.

# Licensing rationale

MailStack is distributed under the **GNU Affero General Public License v3.0 or later** (`AGPL-3.0-or-later`). The complete, unmodified license text is stored in the repository root at `LICENSE`.

## Why AGPL fits this project

MailStack is network-accessible server software. The AGPL preserves the normal freedoms to run, inspect, modify and redistribute the software while requiring operators who provide a modified version over a network to offer the corresponding source under the same license terms. This helps keep improvements to the hosted platform available to users and the community.

A permissive license was considered, but it would allow modified hosted versions to remain closed. The project owner selected AGPL for the public release candidate because reciprocal source availability is a material project goal.

## Third-party software

Dependencies retain their own copyright and license terms. The direct dependency inventory is in `DEPENDENCY_REVIEW.md` and `../mailbox-app/LICENSES.md`. The release owner must confirm ownership of all project code and final license compatibility before public publication.

## Branding

The software license does not automatically grant trademark rights in the MailStack or Vib Tools names or visual identity. See `BRANDING.md`.

This document is an engineering rationale, not legal advice.

# MailStack user guide

- Sign in using the account supplied by the administrator.
- The dashboard and mailbox list show only mailboxes assigned to that account.
- Click an email address to copy it.
- New indexed messages and counters update without reloading the page.
- Opening a message marks it read automatically.
- Use **Mark unread** to return a message to unread state.
- In-app notifications always work while the page is open. Browser notifications are optional and require clicking **Enable notifications**.
- Message or mailbox deletion controls appear only when the administrator grants the matching permission.
- Password changes and public password reset are intentionally unavailable.
